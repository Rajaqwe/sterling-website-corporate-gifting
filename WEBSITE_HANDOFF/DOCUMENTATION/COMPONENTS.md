# Components

**Layout Components**:
- `NavbarClient.tsx` & `Navbar.tsx`: Main navigation.
- `SearchBar.tsx`: Global search with cmdk.
- `CartDrawer.tsx`: Slide-out cart summary.

**Product Components**:
- `ProductDetailClient.tsx`: Main PDP logic (variants, quantity, add to cart, quote request).
- `ProductCard.tsx`: Used in PLPs and related products.
- `QuoteRequestModal.tsx`: Modal form for requesting quotes.
- `TieredPricingTable.tsx`: Displays volume discounts.
- `ProductCustomization.tsx`: Handles branding options.

**UI Primitives (Shadcn)**:
- Button, Input, Sheet, DropdownMenu, etc.
