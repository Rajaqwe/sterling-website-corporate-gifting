# Design System

**Styling**: Tailwind CSS
**UI Framework**: Shadcn UI
**Typography**: Custom fonts configured in Next.js (likely a sans and serif combo based on classes like `font-serif`).
**Colors**: Defined in `tailwind.config.ts` (uses variables for primary, secondary, background, text, destructive, etc).
**Animations**: Uses `tailwindcss-animate` for fades, slide-ins, etc.
**Icons**: `lucide-react`

Most UI components follow a sleek, modern B2B e-commerce aesthetic with cards, borders, and muted backgrounds.
