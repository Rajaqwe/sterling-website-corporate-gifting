# Project Overview

**What the website is**: Sterling Corporate is a B2B e-commerce platform dedicated to corporate gifting.
**Purpose**: Allows corporate buyers to browse gifts, configure branding options, add items to a cart, and checkout or request bulk quotes.
**Target users**: Corporate procurement, HR, marketing professionals looking for employee/event gifts.
**Main functionality**: 
- Browse categorized gifts
- Product details with variants and branding customizations
- Dynamic bulk pricing tiers
- Cart and Checkout system (with guest support)
- Quote request system
- Search functionality
**Current development status**: Under active development (not finished). Core e-commerce flow (Cart, Checkout, Quotes) exists but some features may need refinement. Recently fixed line-item pricing, guest carts, and unified search logic.
